# 功能规范：iOS 风格全局导航与主页设计

**功能分支**: `001-global-nav`
**创建日期**: 2025-11-26
**状态**: 草稿
**用户需求**: "全局交互逻辑修改为类似ios的逻辑，设计两个全局按钮(返回/Home)，各个功能页面在主页上稀疏排布，类似于各个App，进入每个功能都全屏显示，左侧留出全局按钮。主页上显示常用的功能widget及图标，常用的功能有：温度/风扇/LED灯/开始打印超大图片按钮(打印中切换成进度及快捷暂停/取消按钮的卡片)；设置/控制/文件等以图标形式显示"

## 用户场景与测试 *(必填)*

### 用户故事 1 - 主页显示常用功能和快捷操作 (优先级: P1)

用户在主页上可以直接看到并操作常用功能的 Widget（温度、风扇、LED 灯、打印控制），同时可以看到功能入口图标（设置、控制、文件等）。Widget 显示实时状态并支持直接快捷操作。

**优先级理由**: 这是核心的主页体验，让用户无需进入子页面就能快速查看状态和执行常用操作，提供最高效的交互。

**独立测试**: 可以通过显示主页、验证 Widget 显示实时数据、点击 Widget 执行操作来测试。立即提供查看状态和快捷操作的价值。

**验收场景**:

1. **给定** 用户打开应用，**当** 主页加载时，**那么** 显示温度、风扇、LED、打印控制的 Widget 和功能图标
2. **给定** 打印机正在运行，**当** 用户查看主页，**那么** Widget 显示实时的温度、风扇状态
3. **给定** 用户在主页上，**当** 用户查看布局，**那么** Widget 区域和图标区域清晰分离，易于识别

---

### 用户故事 2 - 在主页上调节温度 (优先级: P1)

用户可以直接在主页上点击温度 Widget 调节温度值。点击后弹出扁平键盘页面供输入，输入完成后可通过点击背景、再次点击 Widget、或点击键盘的确定/取消按钮来隐藏键盘。

**优先级理由**: 温度调节是高频操作，在主页上直接操作大幅提升效率，避免进入子页面的繁琐流程。

**独立测试**: 可以通过点击温度 Widget、验证键盘弹出、输入数值、确认键盘隐藏和温度值更新来测试。

**验收场景**:

1. **给定** 用户在主页上，**当** 用户点击温度 Widget，**那么** 弹出扁平键盘页面供输入温度值
2. **给定** 键盘已弹出，**当** 用户点击背景区域，**那么** 键盘隐藏，温度值不变
3. **给定** 键盘已弹出，**当** 用户再次点击温度 Widget，**那么** 键盘隐藏，温度值不变
4. **给定** 键盘已弹出，**当** 用户输入数值并点击确定，**那么** 键盘隐藏，温度值更新为输入值
5. **给定** 键盘已弹出，**当** 用户点击取消按钮，**那么** 键盘隐藏，温度值不变

---

### 用户故事 3 - 在主页上控制风扇和 LED (优先级: P1)

用户可以直接在主页上点击风扇和 LED Widget 进行快捷控制（如开关、调节速度/亮度）。操作直接在 Widget 上完成，无需进入子页面。

**优先级理由**: 风扇和 LED 是常用控制项，主页快捷操作提升用户体验，符合高效交互原则。

**独立测试**: 可以通过点击风扇/LED Widget、执行操作、验证状态更新来测试。

**验收场景**:

1. **给定** 用户在主页上，**当** 用户点击风扇 Widget，**那么** 可以直接控制风扇（如开关、调速）
2. **给定** 用户在主页上，**当** 用户点击 LED Widget，**那么** 可以直接控制 LED（如开关、调节亮度）
3. **给定** 用户操作 Widget，**当** 操作完成，**那么** Widget 实时显示更新后的状态

---

### 用户故事 4 - 主页打印控制：待机时显示超大开始按钮 (优先级: P1)

当打印机待机时，主页显示超大的"开始打印"按钮，用户点击后可以快速启动打印。

**优先级理由**: 开始打印是最核心的操作，超大按钮降低误操作，提供清晰的视觉引导。

**独立测试**: 可以通过在待机状态显示主页、验证超大按钮存在、点击按钮启动打印来测试。

**验收场景**:

1. **给定** 打印机处于待机状态，**当** 用户查看主页，**那么** 显示超大的"开始打印"按钮
2. **给定** 超大开始打印按钮显示，**当** 用户点击按钮，**那么** 启动打印流程
3. **给定** 主页布局，**当** 显示开始打印按钮，**那么** 按钮在视觉上突出显示，易于点击

---

### 用户故事 5 - 主页打印控制：打印中切换为进度卡片 (优先级: P1)

当打印机正在打印时，主页的打印区域从超大开始按钮切换为进度卡片，显示打印进度，并提供暂停/取消快捷按钮。点击暂停/取消按钮直接执行操作，点击卡片其他区域进入打印详情页。

**优先级理由**: 打印中需要实时查看进度和快速控制，卡片形式既提供信息也提供快捷操作。

**独立测试**: 可以通过启动打印、验证卡片切换、点击快捷按钮、点击卡片区域来测试。

**验收场景**:

1. **给定** 打印开始，**当** 主页刷新，**那么** 超大开始按钮切换为进度卡片，显示打印进度
2. **给定** 进度卡片显示，**当** 用户点击暂停按钮，**那么** 打印暂停，按钮状态更新
3. **给定** 进度卡片显示，**当** 用户点击取消按钮，**那么** 打印取消，卡片切换回开始按钮
4. **给定** 进度卡片显示，**当** 用户点击卡片的非按钮区域，**那么** 进入打印详情页（全屏）
5. **给定** 打印完成，**当** 主页刷新，**那么** 进度卡片切换回超大开始按钮

---

### 用户故事 6 - 从主页进入功能全屏页 (优先级: P1)

用户可以通过点击主页上的功能图标（设置、控制、文件等）进入对应功能的全屏页面。全屏页面左侧显示返回和主页两个全局导航按钮。

**优先级理由**: 这是进入深层功能的核心导航模式，所有高级功能都依赖此模式。

**独立测试**: 可以通过点击功能图标、验证全屏页面打开、确认全局按钮可见来测试。

**验收场景**:

1. **给定** 用户在主页上，**当** 用户点击功能图标（如"设置"），**那么** 进入设置功能的全屏页面
2. **给定** 用户进入全屏功能页，**当** 用户查看屏幕左侧，**那么** 返回和主页两个全局按钮可见且可操作
3. **给定** 用户在全屏页面，**当** 功能页面内容显示，**那么** 全局按钮不遮挡功能内容

---

### 用户故事 7 - 使用全局按钮导航 (优先级: P1)

用户可以在任何全屏功能页面使用左侧的全局导航按钮。点击"主页"按钮返回主页，点击"返回"按钮返回上一级页面（如果在功能根页面则返回主页）。

**优先级理由**: 全局导航是 iOS 风格交互的核心，用户需要始终能够返回主页或上一级。

**独立测试**: 可以通过进入功能页、点击全局按钮、验证导航行为来测试。

**验收场景**:

1. **给定** 用户在任何全屏功能页，**当** 用户点击主页按钮，**那么** 返回主页，关闭当前功能页
2. **给定** 用户在功能的嵌套页面，**当** 用户点击返回按钮，**那么** 返回功能内的上一级页面
3. **给定** 用户在功能的根页面，**当** 用户点击返回按钮，**那么** 返回主页
4. **给定** 用户点击全局按钮，**当** 导航执行，**那么** 导航在 300 毫秒内完成，体验流畅

---

### 用户故事 8 - 主页布局清晰分区 (优先级: P2)

主页布局将常用功能 Widget 和功能图标清晰分区，Widget 区域突出显示实时状态，图标区域稀疏排布，类似 iOS 主屏幕。

**优先级理由**: 提升主页美观性和可用性，但基本功能不依赖特定布局方式。

**独立测试**: 可以通过显示主页、验证布局分区、确认视觉层次来测试。

**验收场景**:

1. **给定** 用户打开主页，**当** 查看布局，**那么** Widget 区域和图标区域有明确的视觉分隔
2. **给定** 主页显示，**当** 用户查看 Widget 区域，**那么** Widget 以卡片形式呈现，突出实时数据
3. **给定** 主页显示，**当** 用户查看图标区域，**那么** 图标稀疏排布，易于点击，不拥挤

### 边缘情况

- 当用户在主页上点击返回按钮时会发生什么？（应该没有效果或提供已在顶层的反馈）
- 系统如何处理快速点击导航按钮？（应该防抖或排队导航操作以防止错误）
- 如果功能加载中用户点击主页或返回按钮会发生什么？（应该取消加载或完成当前操作后再导航）
- 键盘弹出时用户点击主页按钮会发生什么？（应该先隐藏键盘并取消输入，或直接导航并自动隐藏键盘）
- 打印进度卡片上的暂停/取消按钮和卡片可点击区域如何区分？（按钮区域需要明确的点击区域，避免误触）
- 当 Widget 正在更新数据时用户点击会发生什么？（应该防止操作或提供加载状态反馈）
- 温度键盘弹出时，其他 Widget 是否可操作？（应该禁用或显示遮罩层，强制用户先完成当前输入）
- 多个温度 Widget 时（热床、喷头），如何区分键盘对应的目标？（键盘应该关联到触发它的 Widget，显示提示信息）

## 需求 *(必填)*

### 功能需求

**主页布局与内容**

- **FR-001**: 系统必须在主页上显示常用功能 Widget 区域，包括温度、风扇、LED、打印控制
- **FR-002**: 系统必须在主页上显示功能图标区域，包括设置、控制、文件等功能入口
- **FR-003**: Widget 区域必须实时显示设备当前状态（温度值、风扇状态、LED 状态等）
- **FR-004**: 主页布局必须将 Widget 区域和图标区域清晰分离，视觉层次分明

**Widget 交互**

- **FR-005**: 温度 Widget 必须支持点击后弹出扁平键盘页面供用户输入温度值
- **FR-006**: 键盘页面必须提供确定和取消按钮
- **FR-007**: 系统必须支持以下方式隐藏键盘：点击背景区域、再次点击温度 Widget、点击键盘的确定或取消按钮
- **FR-008**: 点击确定按钮时，系统必须应用输入的温度值并隐藏键盘
- **FR-009**: 点击取消按钮或背景区域时，系统必须放弃输入并隐藏键盘，温度值不变
- **FR-010**: 风扇 Widget 必须支持直接在主页上操作（如开关、调速）
- **FR-011**: LED Widget 必须支持直接在主页上操作（如开关、调节亮度）
- **FR-012**: Widget 操作完成后必须实时更新显示状态

**打印控制卡片**

- **FR-013**: 当打印机待机时，主页必须显示超大的"开始打印"按钮
- **FR-014**: 当打印开始时，系统必须将超大开始按钮切换为进度卡片
- **FR-015**: 进度卡片必须显示打印进度信息
- **FR-016**: 进度卡片必须提供暂停和取消快捷按钮
- **FR-017**: 点击暂停按钮必须直接暂停打印，无需进入详情页
- **FR-018**: 点击取消按钮必须直接取消打印，无需进入详情页
- **FR-019**: 点击进度卡片的非按钮区域必须进入打印详情页（全屏）
- **FR-020**: 当打印完成或取消时，系统必须将进度卡片切换回超大开始按钮

**全局导航**

- **FR-021**: 系统必须提供两个全局导航按钮（返回和主页），位于屏幕左侧
- **FR-022**: 当用户从主页进入功能全屏页时，全局导航按钮必须保持可见
- **FR-023**: 点击主页按钮时，系统必须从任何位置返回主页
- **FR-024**: 点击返回按钮时，系统必须返回上一级页面
- **FR-025**: 当用户在功能根页面点击返回按钮时，系统必须返回主页
- **FR-026**: 系统必须为每个功能维护导航历史栈以支持层次返回
- **FR-027**: 全局导航按钮必须在全屏功能页左侧保留空间，不遮挡功能内容

**功能图标导航**

- **FR-028**: 点击主页上的功能图标时，系统必须以全屏模式打开对应功能
- **FR-029**: 功能图标必须清晰可识别，有图标和标签
- **FR-030**: 图标区域必须采用稀疏网格布局，类似 iOS 主屏幕

**交互反馈**

- **FR-031**: 所有可点击元素（Widget、按钮、图标）必须提供视觉点击反馈
- **FR-032**: 导航操作必须在 300 毫秒内完成以保证流畅体验
- **FR-033**: 键盘弹出时，系统必须禁用或遮罩其他 Widget 的交互，确保用户专注当前输入

### 关键实体

- **主页 (Home Screen)**: 应用的入口页面，包含 Widget 区域和功能图标区域
- **Widget**: 主页上的可交互卡片，显示实时状态并支持快捷操作（温度、风扇、LED、打印）
- **打印控制卡片 (Print Control Card)**: 具有两种状态的特殊 Widget
  - 待机状态：显示超大"开始打印"按钮
  - 打印中状态：显示进度信息、暂停/取消按钮
- **扁平键盘页 (Flat Keyboard Overlay)**: 用于温度输入的浮层页面，提供数字键盘和确定/取消按钮
- **功能图标 (Feature Icon)**: 主页上的功能入口，点击后进入对应功能的全屏页面
- **全局导航按钮 (Global Navigation Buttons)**: 返回和主页按钮，在所有全屏功能页左侧可见
- **导航栈 (Navigation Stack)**: 记录用户在功能内的页面浏览历史，支持返回操作
- **功能页 (Feature Page)**: 全屏显示的功能界面（设置、控制、文件等）

## 成功标准 *(必填)*

### 可衡量的成果

- **SC-001**: 用户可以在主页上通过 1 次点击查看所有关键设备状态（温度、风扇、LED、打印进度）
- **SC-002**: 用户可以在主页上通过 2 次点击完成温度调节（点击 Widget + 输入确认）
- **SC-003**: 用户可以在主页上通过 1 次点击控制风扇、LED 和打印（暂停/取消）
- **SC-004**: 用户可以在 1 次点击内从任何功能页返回主页
- **SC-005**: 键盘弹出和隐藏动作在 200 毫秒内完成，体验即时
- **SC-006**: 打印状态切换（待机↔打印中）在 300 毫秒内刷新 UI
- **SC-007**: 导航操作（进入功能、返回、回主页）在 300 毫秒内完成
- **SC-008**: Widget 状态更新延迟不超过 500 毫秒，保证实时性
- **SC-009**: 95% 的用户能够在首次使用时成功完成主页快捷操作和导航
- **SC-010**: 零次用户因误触打印卡片按钮而意外暂停/取消打印

## 假设 *(可选)*

- 应用运行在触摸屏设备上，屏幕分辨率足以同时显示 Widget 和功能图标
- 用户熟悉 iOS 风格的交互模式（主屏幕、返回导航）
- 打印机通过 Moonraker API 提供实时状态数据（温度、风扇、打印进度等）
- 后端已实现温度、风扇、LED 的控制接口
- 扁平键盘仅用于数字输入，不需要完整字母键盘
- 主页 Widget 数量控制在 4-6 个，保持主页简洁
- 功能图标数量适中（6-12 个），可以在主页上清晰显示

## 依赖项 *(可选)*

- 后端必须提供实时状态推送机制（WebSocket 或轮询）以更新 Widget 数据
- 后端必须提供温度、风扇、LED 的控制 API
- 后端必须提供打印控制 API（开始、暂停、取消）和进度查询 API
- QML 布局系统必须支持响应式布局以适配不同屏幕尺寸
- 触摸系统必须支持精确的点击区域检测，避免误触

## 范围外 *(可选)*

- 主页 Widget 的自定义和重新排序
- 功能图标的自定义和重新排序
- Widget 的展开/收起动画
- 打印详情页的具体设计（仅定义入口）
- 设置、控制、文件等功能页的具体内容（仅定义导航）
- 多语言支持
- 主题和颜色自定义
- 键盘的高级功能（历史记录、快捷温度值）
- 打印文件选择流程（仅定义开始打印入口）
- 离线模式和错误处理的详细策略
