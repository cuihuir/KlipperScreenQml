## Custom Icons

QtKs supports custom icons that override theme icons. To add custom icons:

1. Create a directory for your custom icons (e.g., `assets/custom_icons/`)
2. Add SVG or PNG files with the same names as icons you want to override
3. Enable custom icons in `config.json`:

```json
{
  "theme": {
    "selected_theme": "material-dark",
    "custom_icons_enabled": true,
    "custom_icons_dir": "assets/custom_icons"
  }
}
```

4. Restart the application

**Fallback Priority**:
- Custom icons (highest priority)
- Current theme icons
- Base theme icons
- Placeholder icon (lowest priority)

**Supported Formats**: SVG (recommended), PNG

**Example Custom Icon** (`assets/custom_icons/home.svg`):
```xml
<?xml version="1.0" encoding="UTF-8"?>
<svg width="24" height="24" viewBox="0 0 24 24" xmlns="http://www.w3.org/2000/svg">
  <path d="M10 20v-6h4v6h5v-8h3L12 3 2 12h3v8z" fill="currentColor"/>
</svg>
```
